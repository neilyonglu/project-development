#ISSUE Architecture

How to read this diagram

Overview

Requests flow through the project layers and results return to the caller. Part tabs follow branches in merge order; Part N shows layers up to N. Replace this example legend with the actual project architecture.

Node types

  • Colour = layer; the first, second and third layers each take their own colour
  • Database table
  • External service, such as an LLM
  • Test file; hide with Show tests
  • Solid border: file read
  • Dashed border: file unread
  • Faded grey box: the file does not exist yet, it is planned
  • Parallelogram: data or configuration file without active behavior
  • Thick magenta border: added in this Part

Edge types

  • Call, read or write; labels show input → output
  • Cross-layer call, such as a backend calling a service
  • Returned result
  • ①②③Sequential steps from one origin, completed in order

Controls

  • Hover a node to see its purpose
  • Click a node to open its file and function details; connected edges turn red
  • Ctrl + mouse wheel: zoom around the pointer
  • Click the − beside a block title to fold the block into one box; click that box to open it again
  • Press F5 after editing the file
